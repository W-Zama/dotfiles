# dotfiles

## Installation

### 1. Clone the repository

```bash
git clone git@github.com:W-Zama/dotfiles.git ~/dotfiles
```

### 2. Run the install script

```bash
.bin/install.sh
```

`~`配下にdotfileのシンボリックリンクを作成します。

## 管理ファイル一覧

管理対象のファイルは [.gitignore](.gitignore) を参照してください（ホワイトリスト形式で管理）。
